# LinuxXterm

LinuxXterm — настольное приложение для Linux, объединяющее SSH-терминал и файловый менеджер SFTP.

Это небольшой Linux-ориентированный аналог приложений для удалённого администрирования, таких как MobaXterm: он собирает в одном окне подключения к серверам, терминальные вкладки и работу с удалёнными файлами. LinuxXterm — независимый проект, не связанный с Mobatek и не являющийся продуктом MobaXterm.

## Возможности

- Сохранение и поиск профилей SSH-подключений.
- Отдельная терминальная вкладка для каждого подключения.
- Файловый менеджер SFTP с отдельной сессией на вкладку сервера.
- Загрузка и выгрузка файлов, в том числе перетаскиванием, с отображением прогресса.
- Отображение базовых сведений о сервере: загрузки CPU и RAM, состояния дисков.
- Настройки шрифта, использующие системный моноширинный шрифт.
- Опциональный режим совместимости со старыми SSH-серверами для выбранного профиля.

## Системные требования

- Linux с графическим рабочим столом.
- CMake 3.16 или новее и компилятор C++17.
- Qt 6: Core, Gui, Widgets и Network.
- QTermWidget 6 (`qtermwidget6`).
- `libssh2`.
- OpenSSL (libcrypto).
- OpenSSH-клиенты `ssh` и `sftp`.
- `sshpass` для автоматической парольной аутентификации в функциях, использующих системный OpenSSH.

Пакеты разработки и их названия различаются между дистрибутивами. Установите соответствующие Qt 6, QTermWidget 6, libssh2, CMake и C++ build tools из репозиториев своего дистрибутива.

## Сборка

Из корня репозитория выполните:

```bash
cmake -S . -B build
cmake --build build --parallel
```

Исполняемый файл появится по пути `build/linuxxterm`.

## Установка

Установщик из каталога `packaging` копирует собранное приложение в `/usr/local/bin`, а значок и desktop-файл — в системные каталоги. После сборки запустите скрипт из каталога `packaging`:

```bash
cd packaging
sudo ./install.sh
```

Для запуска после установки:

```bash
linuxxterm
```

## Использование

1. Запустите LinuxXterm и добавьте профиль подключения: имя, адрес сервера, порт и логин.
2. Выберите способ аутентификации — пароль или приватный SSH-ключ.
3. Для старого SSH-сервера включайте совместимость только в настройках соответствующего профиля и только для доверенного сервера.
4. Выберите профиль и нажмите «Подключить». Для перехода к файлам сервера откройте вкладку «Файлы».
5. Перетаскивайте файлы между локальной системой и SFTP-файловым менеджером; ход передачи отображается внизу окна.

## Важное замечание о старых SSH-серверах

Режим совместимости разрешает устаревшие SSH-алгоритмы для отмеченного профиля. Это может снижать криптографическую стойкость соединения. Не включайте его без необходимости и не используйте для неизвестных или недоверенных серверов. Для остальных профилей и системной криптографической политики этот режим не предназначен.

## Хранение данных

Профили и данные приложения хранятся локально в `~/.config/linuxxterm`. Пароли профилей шифруются AES-256-GCM с ключом, полученным из мастер-пароля с помощью PBKDF2-HMAC-SHA-256. При первом разблокировании старые пароли переносятся из профилей и прежнего хранилища; для миграции используется тот же мастер-пароль. При запуске `sshpass` пароль передаётся отдельным локальным каналом, а не через аргументы команды или переменные окружения. Не удаляйте файлы данных до завершения миграции и создания резервной копии.

Не включайте в публичный репозиторий свои файлы конфигурации, парольное хранилище, приватные ключи, логи или другие секреты. Не используйте репозиторий как место для резервной копии пользовательских данных.

Файлы хранилища и мастер-пароля доступны только текущему пользователю системы. Механизм хранения паролей проекта не проходил независимый аудит безопасности. Не полагайтесь на LinuxXterm как на сертифицированное или усиленное хранилище секретов.
